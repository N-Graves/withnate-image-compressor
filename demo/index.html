Why it sometimes comes out bigger

A JPEG straight out of a phone has already been compressed once. Re-encoding it a second time cannot recover what the first pass threw away, and often costs a few bytes rather than saving any. When that happens this tool says so plainly instead of handing you a larger file and calling it a saving — keep the original, or drop the longest edge so there is genuinely less picture to store.

Resizing is done in steps

Asking a browser to draw a 6000px photo straight down to 400px in one go throws away most of the pixels without looking at them, and the result crawls with aliasing. This halves the image repeatedly instead, never more than 2× per step, with the last step landing exactly on the size you asked for.

Your photo never leaves the page

Everything happens in your own browser. There is no upload, no storage, and no network request of any kind. One useful side effect: because the image is re-encoded from raw pixels, the file you download carries no EXIF, no camera model and no GPS coordinates — worth knowing before posting a photo taken at home. The colour profile goes the same way, so a wide-gamut image comes back as sRGB.
